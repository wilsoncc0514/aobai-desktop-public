# 自定义皮肤 v2 制作指南

适用当前开发版；自定义皮肤使用图集播放，内置鳌拜的额外动作素材不构成外部皮肤接口。猫的显示画布是 208×208 逻辑像素，不是图集尺寸。请只使用有权处理与分享的照片、绘图和素材。

## 目录与清单

在程序的 `skin/` 中为每只猫建立独立目录，目录内放置 UTF-8 的 `pet.json` 与图集：

```text
skin/
  my-cat/
    pet.json
    spritesheet.webp
    spritesheet@2x.webp
```

```json
{
  "id": "My-Cat",
  "displayName": "我的猫",
  "description": "一只安静的猫",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp",
  "spritesheet2xPath": "spritesheet@2x.webp"
}
```

`id` 为 1–48 位 ASCII 字母、数字或连字符，且不能与其他皮肤重复；`displayName` 不得为空且最多 40 个字符。`description` 和 2x 路径可省略。图集路径为皮肤目录内安全的相对路径，不能使用 `..` 或指向目录外；清单不接受符号链接。程序最多扫描 50 个目录，清单上限 64KB，每张图集上限 20MB。

## 图集

标准图集必须为 **1536×2288**：8 列、11 行，每格 **192×208**；可选 2x 图集为 **3072×4576**。使用透明背景的 PNG 或 WebP；有损 WebP 的品质应以毛边、半透明边缘及实际播放效果检查，而不是依赖固定的品质数字。2x 缺失或无效时会退回标准图集并报告警告。

按当前播放代码，行号从 0 开始：0 待机，1 向右，2 向左，3 挥爪，4 跳跃，5 异常，6 等待，7 运行，8 完成；其余行目前不由这些状态使用。各状态使用的帧数和逐帧时长由程序的 `src/animation/catalog.ts` 决定，清单不能自定义帧率。保持各帧的体型、接触面与尾巴连续；不要只在图集静态预览中判断，需在应用里实际播放及检查缩放后的边缘。

## 加载与检查

把完整目录放进运行包旁的 `skin/`，从状态栏选择“外观 → 重新扫描 skin”，再选择皮肤。开发环境默认使用应用目录下的 `skin/`；如设置 `AOBAI_SKIN_DIR` 则使用指定目录。无效清单或图集应修复后重新扫描；保留原文件和当前可用皮肤，不覆盖已有皮肤目录。仅扫描通过不能证明每一帧的画质或动作自然，仍需实际查看。
